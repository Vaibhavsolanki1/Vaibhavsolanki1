# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of **GitHub Profile 2.0** seriously.

If you discover a security vulnerability or potential risk within this repository (e.g. secret handling, API key exposure, or injection vulnerabilities), please **DO NOT** open a public issue.

Instead, please report the vulnerability directly to the project maintainer via security advisory on GitHub or email.

### Response Process

1. **Acknowledgment**: We will acknowledge receipt of your vulnerability report within 48 hours.
2. **Investigation**: We will investigate the issue and determine its impact and severity.
3. **Patching**: A fix will be developed and verified in a private security branch.
4. **Disclosure**: A public patch release will be published along with appropriate security advisory credit.
